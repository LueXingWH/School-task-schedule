## 1.2.2 — 免手输直达管理页

- Edge 156 实测确认外部进程无法用命令行参数、`microsoft-edge:` 协议或 `--app=` 打开内部管理页；此前“加载完成后打开工作台”报拦截的真正原因是扩展未在当前配置加载或激活配置不一致。
- 按用户反馈改为不覆写剪贴板：界面直接显示管理页网址和扩展路径并配“复制网址”“复制扩展路径”按钮，由用户复制粘贴进入管理页；自动粘贴方案在真实多配置环境不可靠，已移除。
- 状态栏与四步指引写明“开发人员模式”开关位置（Edge 左下角 / Chrome 右上角）；检测结果以加粗行常显；工作台按钮改为打开方法指引。
- 测试架改为直接 spawn 浏览器并经 CDP 附加（launchPersistentContext 托管实例上外部交接不产生新页面），修复 `connectOverCDP` 只断开不退出进程导致的二次启动失败；完整 8 组 EXE 验收在 Edge 156 通过。
