# 校事笺需求基线

权威规格：根目录 `Xiaoshijian_Project_and_Codex_Prompt.md`（2026-10-27），全文适用，原文保留。

目标版本 1.0.0：Windows Chrome MV3 扩展，React/TypeScript，IndexedDB 本地持久化；无账号、无大模型/API 密钥、无 Python 后端、无运行时资源下载。

完整链路：文字/主动网页/图片本地 OCR/PDF 文本与扫描页 OCR/DOCX 段落表格 → 原始数据先保存 → 可解释日期材料候选及依据 → 人工修正 → 截止排序/今日任务/材料勾选 → 完整附件备份恢复。

约束：候选日期不冒充确认日期；缺年不补本机年份；无日期可保存；重解析保留人工编辑和清单状态；失败/中断保留原件；最少权限；包内中英文 OCR；所有解析按真实输入执行。

交付：源码与锁文件、生产 dist/ZIP、中文指南、许可与资源来源、实际测试与验收记录、三分钟演示和 PPT 内容提纲。未实测能力不宣称支持。

## 2026-10-27 补充需求：Edge 适配（1.1.0）

用户追加要求优先完成 Edge 适配。支持范围扩展到 Windows Microsoft Edge，保留 Chrome；在本机真实安装的 Edge 中验证全部核心离线解析、网页采集、持久化和安装恢复。提供 Edge 安装包、`edge://extensions` 安装说明、Chrome → Edge 完整备份迁移说明与真实测试证据。仍不增加模型、API、后台服务、权限或云同步。

## 2026-10-27 补充需求：简化安装与配置（1.2.0）

用户要求优化安装负担，目标为一键安装配置。实现单文件 Windows 便捷安装助手，自动准备离线资源、固定目录、入口与默认设置；真实测试首次加载和重复更新。浏览器原生首次确认不由助手绕过。真正面向普通用户的商店“获取 / 添加”需要开发者账号与审核，先备好提交包和材料，未得到发布授权不直接上架。安装和配置优化不引入常驻服务或模型依赖。

## 2026-10-27 补充需求：可选安装位置（1.2.1）

用户反馈安装助手路径不能选择或更改。新增目录选择和手动输入，默认位置仍保留；安装按钮、扩展加载目录及桌面入口必须实际采用用户选择。更换路径应提示扩展 ID 和备份迁移影响，不能覆盖其他目录文件。

## 2026-10-27 补充需求：修复管理页入口（1.2.2）

用户反馈“打开扩展管理页”无响应。真实复现后修复为可在准备前使用的浏览器启动与管理页地址复制入口，明确地址栏导航步骤、显示网址、处理失败；不能将浏览器进程启动成功冒充管理页已打开。补充真实 WinForms 点击、系统剪贴板、Edge/Chrome 启动和管理页验收。

## 2026-10-27 补充需求：免手输直达管理页（1.2.2）

用户反馈打开浏览器后仍要自己输入网址，且“加载完成后打开工作台”点击后被浏览器拦截。实测 Edge 156 丢弃外部进程传入的内部页参数（含协议与 `--app`）；自动粘贴方案在真实多配置环境不可靠，最终实现改为“显示网址 + 用户自行复制粘贴”，且除用户主动点复制按钮外不写剪贴板。工作台打不开的原因（扩展未在当前配置加载或激活配置不一致）写入状态栏指引与文档，不得宣称绕过浏览器确认。
