## 1.2.2 管理入口验收

旧入口直接向 Edge 传入 `edge://extensions`，实际只打开新标签页。该路径未在旧版安装测试中覆盖，旧文档关于助手直接打开管理页的描述不准确。

新版在准备文件前实际点击 WinForms 的“打开浏览器并复制地址”按钮，验证真实浏览器打开空白页、读取真实系统剪贴板并核对 Edge/Chrome 对应网址，断言状态栏包含地址栏粘贴指引。随后按指引的地址在真实浏览器导航到管理页，检查开发人员模式控件并截图；不将这一步描述为助手自动完成。

原有 8 组安装检查与新增按钮检查合计每个浏览器 9 组。记录分别为 `test-results/setup-results-edge.json`、`test-results/setup-results-chrome.json`，均绑定交付 EXE 的 SHA-256。两个浏览器的核心、ZIP 安装和 26 条单元测试按当前版本回归。

- 实际运行 EXE 的 WinForms 窗口，将任意名称的中文/空格目录填入路径框，调用同一安装按钮，核对全部资源确实写入该目录的 Extension 子目录。
- 检查真实 Windows 快捷方式和 Edge 返回的扩展 ID 与所选路径一致；同目录重复更新后通知、勾选、自定义设置和原文件保留。
- 另选新目录成功，扩展 ID 正确变化，旧目录和旧数据保留，新目录数据库为空，不伪装自动迁移。
- 磁盘根目录、相对路径和非空未管理目录被拒绝，既有重要文件字节不变。

以上与原安装流程合计 **8 组当前 EXE 检查**。记录和预览图见 `test-results/setup-results.json`（含当前二进制 SHA-256）。原 26 条单元回归和两个浏览器业务验收按当前版本重新运行。

## 样例与质量说明

测试图片由 Canvas 生成，正文包含中文、2026 年日期、18:00、材料名称与英文数字；测试时经过真实本地识别，没有把预期文本直接写回解析结果。实际 OCR 识别出标题、日期、材料和 Student Innovation；英文行中的中点被识别为短横线。该样例通过不代表所有海报的识别率。

两页文本 PDF 用真实 Chrome 打印生成并嵌入字体；扫描 PDF 嵌入图片；混合 PDF 由两页文本加一页扫描构成。DOCX 包含真实 OOXML 段落和表格。损坏样例故意放入非对应格式的字节，以验证错误及保留路径。素材在 `tests/fixtures`，可重新生成。用户的原赛事截图没有随本次任务提供，未声称识别过该截图。

公开网页样本：[2026年11月6-7日普通话水平测试网络报名通知](https://jw.nju.edu.cn/e8/28/c26263a845864/page.htm)。仅验证该次可见页面主动采集，不宣称所有学校站点/公众号均可访问。网页标题定位在实测中修正，避免使用网站页眉作为通知标题。

## 未实测或仍需外部材料

- Edge 156 / Chrome 154 已在 Windows 实测；更旧版本、其他操作系统、移动端及企业策略限制环境未列为已验证支持。
- 图片旋转入口与限额保护已实现，尚未逐一验证全部旋转角度、所有图片编码、加密 PDF 和极限大小文件的设备性能。初始保护限额不当作硬件能力承诺。
- 网页选区入口已实现，核心自动化目前重点覆盖全文采集；复杂多栏 PDF、纵排/低清 OCR、复杂否定句需要人工核对。
- 数据库为首次发布 schema v1；已有同版本数据的重开已验证，未来新增 schema 时仍需补充对应升级迁移测试。
- 官方赛事截图、报名表/PPT 模板未提供：已交付演示脚本、PPT 内容提纲与待填材料清单，未核实官方格式、邮件或精确提交时刻，未发送邮件或上架商店。
