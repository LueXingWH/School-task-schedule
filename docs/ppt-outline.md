# 作品 PPT 内容与提交材料清单

本项目未拿到用户原赛事截图或官方附件文件。当前仅依据需求规格整理内容，不推断 PPT 模板、页数、命名、报名表字段、邮件地址或精确提交时刻。官方附件仍由用户获取；不自动报名或发送邮件。

1. **封面**：校事笺——校园通知收集与事项管理插件。作者/学校/指导老师由用户填写。
2. **应用场景**：群文字、校园官网、截图、PDF/Word 分散；学生需要统一核对截止和准备材料。
3. **产品流程**：多源收集 → 原件先保存 → 本地识别 → 保留依据 → 人工核对 → 任务与材料清单。
4. **实际功能**：文字/网页、截图 OCR、PDF 文本与扫描选页、DOCX 段落表格；搜索筛选、排序、今日任务、完成归档、完整备份恢复。
5. **技术特点**：Chrome MV3、React/TypeScript、Vite、IndexedDB/Dexie；Tesseract LSTM 中英离线识别、PDF.js、Mammoth；原件与候选来源关联、Web Locks 串行解析、Blob 及 SHA-256 备份校验。
6. **研发与运行环境**：2026-10-27 完成本版研发和实测（详见验收记录）。Windows 桌面 Chrome；Node 仅用于构建；用户运行不需要 Node/Python/后端。尚未上架，使用已解压扩展加载方式。
7. **使用说明与隐私**：主动收录、随时更正、先备份再卸载；最少权限、无云端上传、无账号/模型 API。
8. **实际效果与边界**：使用真实 OCR 和附件解析的测试截图/文本，报告具体样例和测试范围。测试结果不是推广规模或普遍准确率；复杂版面需人工核对。
9. **运营模式**：当前为本地工具原型/试用版，无收费服务和服务器依赖；可邀请同学自愿试用，尚无实际用户反馈可报告。
10. **演示与后续**：按三分钟脚本展示真实链路；后续依据真实反馈优化规则和复杂版面。未经确认不扩展云同步或聊天功能。

提交前由用户按官方要求逐项核对：

- [ ] 取得官方报名表、作品介绍模板、PPT 模板及命名规则。
- [ ] 填写作者、学校、联系方式等真实身份信息。
- [ ] 按官方格式导出 PPT/作品说明，附实际运行截图。
- [ ] 准备扩展安装包、完整源码、中文指南与真实测试记录。
- [ ] 如要求演示视频，按脚本录制真实操作，避免敏感通知与个人信息。
- [ ] 核对提交渠道、附件大小、文件命名、截止时刻，以官方原文为准。

规格中提到 2026-11-09 征集截止、11-08 内部交付目标；此处不将它们当作已核实的官方精确时刻。
