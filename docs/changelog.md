# 版本记录

## 1.2.2 — 2026-10-27

- 助手启动时自动检测已装过的校事笺：读取浏览器各用户配置记录的已加载扩展（含解压扩展的 ID、路径与启停状态）和目标目录的安装回执。检测到已加载时状态栏显示版本、配置名和目录，“打开工作台”直接可用，安装位置与实际目录不一致时自动填回，不再要求每次重新安装；只找到安装回执时引导完成浏览器首次加载。
- 优化便捷安装：浏览器新窗口打开后，助手自动在地址栏粘贴管理页地址并回车，直接进入 `edge://extensions/`（Chrome 同理），用户不再需要手动输入网址；自动跳转被系统拒绝时自动降级为“地址已复制，Ctrl+V 回车”指引，状态栏始终说明当前情况。
- 自动进入管理页后，助手会把扩展加载目录放入剪贴板，“加载解压缩的扩展”的文件夹窗口直接 Ctrl+V 即可选择；界面指引同步精简为三步。
- “加载完成后打开工作台”补充失败原因指引：无法访问意味着扩展尚未在当前配置加载或激活配置不一致。
- Edge 156 实测确认外部进程无法通过命令行参数、`microsoft-edge:` 协议或 `--app=` 打开内部管理页；自动化仅覆盖地址栏粘贴，不替代任何浏览器确认动作。
- 修复原“打开扩展管理页”按钮无明显反馈的问题；管理入口在准备文件前也可使用；首次准备使用同一入口，浏览器启动失败不再误报文件安装失败。
- 补充实际 WinForms 按钮、系统剪贴板、真实浏览器新窗口及管理页到达检查；交付要求 Edge 与 Chrome 当前 EXE 均通过按钮验收。

## 1.2.1 — 2026-10-27

- 修复安装助手路径框只读、安装按钮忽略用户路径的问题；新增“浏览…”和可直接编辑的安装位置。
- 支持任意文件夹名，显示实际 Extension 子目录；复制路径和快捷方式使用所选位置。
- 更新同一目录保留原 ID 和数据；更换目录有迁移提示，保留旧安装。拒绝磁盘根目录、相对路径和非空未管理目录。
- 实际通过 WinForms 输入框与安装按钮测试中文/空格自选路径，新增换目录和原文件保护回归。

## 1.2.0 — 2026-10-27

- 新增无需 Node/Python/管理员的单文件 Windows 便捷安装助手，内嵌完整离线扩展资源，自动放置到固定用户目录、逐文件校验、创建桌面入口并打开扩展管理页。
- 浏览器首次加载后自动应用默认设置并显示欢迎页；重复加载/更新保留自定义设置，不重复弹欢迎页。
- 首次浏览器开发人员模式和加载确认仍需用户完成，助手界面明确区分“文件准备成功”与“扩展已加载”，不写强制安装策略或开放生产调试端口。
- 重复准备保留扩展目录/ID，并保留旧文件副本；支持旧 ZIP 目录通过备份迁移。
- 补充实际 EXE、中文/空格路径、真实快捷方式、正常 Edge 命令行入口、自动配置及重复更新的数据保留验收。
- 准备 Edge 商店描述、权限说明、审核操作和隐私正文；尚未使用开发者账号提交或上架。

## 1.1.0 — 2026-10-27

- 新增 Windows Microsoft Edge 支持和独立安装包，保留 Chrome 支持；两个浏览器共享同一套 MV3 资源，无新增权限和服务。
- 在真实安装的 Edge 156.0.4314.42 验证离线 OCR、剪贴板、PDF/DOCX、网页采集、持久化及完整恢复，补充 Chrome → Edge 备份迁移与附件 SHA-256 核对。
- 浏览器自动化按真实 Chrome/Edge 分别运行和保存证据，等待弹窗实际按钮挂载，识别 Edge 的受限内部页面地址。
- 构建与交付按 package 版本生成 Edge/Chrome ZIP，交付前要求当前版本两个浏览器的核心与安装验收通过。数据库 schema 仍为 v1。
- 更新设置页支持范围、Edge 安装/原目录升级/迁移说明，工作台版本号跟随 package 版本。

## 1.0.0 — 2026-10-27

首次可安装交付版本。由空目录依次完成本地事项管理、可解释规则、多来源真实离线解析、数据备份、安全边界、Chrome 验收和安装交付；中间阶段没有对外发布版本。

- 文字和主动网页采集，选区优先、表单排除、重复网址提示、受限页提示。
- 截图上传/拖入/真实剪贴板粘贴，中文英文离线 OCR、原图预览旋转。
- 多页文本 PDF、混合/扫描 PDF 选页渲染 OCR，实际页码和处理状态。
- DOCX 正文、段落和表格行，可选材料上下文；旧 DOC 明确提示。
- 原始输入与任务先存；可编辑草稿、候选依据、截止核对、任务计划、清单与完成归档。
- IndexedDB schema v1、关联清理、跨页面同步、跨窗口解析锁、取消和中断恢复。
- 搜索筛选排序、自然日今日/逾期规则、完整 ZIP 备份与校验、新副本合并恢复。
- 生产 MV3 CSP/本地 Worker/WASM，全部 OCR/PDF 资源随包；源码锁文件、指南、许可、演示及 PPT 提纲。

测试范围及待确认的赛事官方材料见 `acceptance.md`。没有上架、外部部署、自动发送邮件、每日教学安排或后台模型服务。
