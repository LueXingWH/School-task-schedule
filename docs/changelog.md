# 版本记录

## 1.4.0 — 2026-10-28

- PDF、截图、粘贴文字统一提取标题、待办及对应时间，补充 UTF-8 TXT/Markdown 上传。待办保留原文区间、来源和 PDF 页码，可编辑、忽略和核对采纳；可选事项默认不选，缺年、暂定、无效或多时间保留待确认。
- 新增右上角常驻“确认日程”，一次采纳已选且有可靠时间的事项，并确认当前主截止日；重复确认或多个来源的同名同日事项不重复建任务。保留个人任务时刻和勾选状态。
- 详情改为“待办与日程 / 材料清单 / 时间依据 / 原文与来源”四个页签，依据与原件默认折叠，长列表在区域内滚动，减少页面纵向长度。
- 扫描和混合 PDF 自动 OCR 前 10 个扫描页，文本页直接提取；剩余扫描页明确提示选页继续。重试保留已成功 OCR 的页，空白识别结果显示部分完成。
- 改善截图标题选择、PDF 中文文本项连接、中文上午/下午/点半时刻及多事项时间角色区分。
- 新增字段按需兼容原数据，旧通知首次打开补提取待办；备份校验和恢复覆盖待办依据、采纳日程与新 ID 关联。数据库索引仍为 v1，权限和 CSP 不变，核心处理离线。
- 验证详情及限制见 `acceptance.md` 与 `known-limitations.md`。

## 1.3.0 — 2026-10-28

界面与功能优化版本。数据结构、权限、CSP 与本地处理边界不变。

**工作台界面**

- 重写样式系统为令牌化的可维护 CSS（原文件被压成一行的写法废弃），统一墨绿/纸白配色、圆角、阴影与字号层级，补齐空状态、Toast、进度条、语义徽章（待核对/进行中/已完成/归档）与表单焦点态。
- 首页新增概览带：今日要办、材料已备（含总分母）、等你核对三项并排，右侧保留“收录一份通知”；指标卡加图标与语义色，逾期为红色强提示。
- 通知卡片改为「左侧状态色条 + 徽章行 + 标题 + 来源/材料进度 + 右侧日期与剩余天数胶囊」；逾期与三日内分别用红/琥珀强调，候选日期在日期块下注明“机器候选 · 待核对”。
- 详情页截止日改为横向信息条并显示剩余天数；材料区新增进度条与“全部标记已备”；新增“今天 / 明天 / 一周后”快捷设置；个人任务中当天项高亮。
- 导入页新增拖拽高亮、字符计数与“继续处理最近的通知”；设置页新增通知数/原件数/材料已备比例统计、键盘快捷键说明，并把清空数据独立成不可撤销区块。
- 工具栏搜索框加图标与 `/` 提示；移动端（≤760px）改为吸顶紧凑导航，修复设置入口与导航项重叠、卡片日期块挤压、空状态排版散乱的问题。
- 工具栏弹窗（Popup）新增“最近收录”三条直达入口，并统一样式。

**功能**

- 新增剩余天数计算（`daysUntil` / `daysLabel` / `deadlineTone`，按本地时区解析日期，避免 `new Date('YYYY-MM-DD')` 的 UTC 偏移）与整体材料准备度（`overallProgress`，排除“无需提交”项）。
- 首页今日清单里的个人任务可直接勾选完成，不必进入详情页。
- 键盘快捷键：`/` 聚焦搜索、`Esc` 清空并退出、`N` 进入收录页。
- 搜索无结果与列表为空区分文案，并提供“清除筛选条件”。

**安装助手**

- 界面重做为「品牌带 + 两张编号卡片 + 检测结果卡 + 状态栏」：自绘圆角卡片、浅绿品牌带、步骤序号圆标，窗口放大到 780×816 并支持滚动，避免小屏溢出。
- 四步指引由一整段密集小字改为 2×2 步骤网格（标题 + 说明），管理页网址、`复制网址`、`打开扩展管理页`、`复制扩展路径`、`如何打开工作台` 按操作顺序排列在同一张卡内。
- 新增准备进度条与分阶段状态文案；检测结果常显并带颜色（已加载/停用/仅准备过文件/未发现），配套一行解释“只读配置、不改浏览器设置”。
- 剪贴板约定不变：助手不主动覆写剪贴板，仅在用户点“复制网址 / 复制扩展路径”时写入；读取剪贴板失败时降级提示，不中断流程。

**验收**

- 26 条 Vitest 规则/备份回归通过。
- 真实 Edge 与 Chrome 各 15 组端到端流程通过（含 OCR、PDF/DOCX、备份恢复、网页采集、窄窗口布局）。
- 当前 EXE 在两个浏览器各 12 项安装验收通过（含中文/空格路径逐文件字节核对、快捷方式、检测、重复更新保留数据、非法目录拒绝）。
- 本机桌面会话不可访问系统剪贴板时，安装验收的剪贴板断言降级为读取助手报告字段，确认未写入管理页地址；该项在 `setup-results.json` 中单列说明。

## 1.2.2 — 2026-10-27

- 开发人员模式指引写到位（用户反馈“一直不知道开发者模式怎么打开”）：界面四步指引和状态栏提示均写明开关的确切位置——Edge 在扩展管理页**左下角**、Chrome 在**右上角**（实测截图确认），并明确“先开开关，再点加载解压缩的扩展”的顺序。
- 检测结果改为界面底部独立的加粗“检测结果”一行，启动即显示四种状态之一（已加载 / 已加载但被停用 / 仅准备过文件 / 未发现），不再只在状态栏里滚动。
- “加载完成后打开工作台”改为“如何打开工作台”：不再自动请求浏览器打开工作台地址（用户实测该跳转会被 Edge 拦截），点击后直接给出三种打开方式（桌面快捷方式 / 工具栏图标 / 管理页“详细信息”）及配置不一致时的处理方法；检测到加载配置时写明配置名。
- 助手启动时自动检测已装过的校事笺：读取浏览器各用户配置记录的已加载扩展（含解压扩展的 ID、路径与启停状态）和目标目录的安装回执。检测到已加载时状态栏显示版本、配置名和目录，“复制扩展加载目录”直接可用，安装位置与实际目录不一致时自动填回，不再要求每次重新安装；只找到安装回执时引导完成浏览器首次加载。
- 管理页进入方式改为“显示网址 + 用户自行复制粘贴”：助手打开浏览器新窗口但不写剪贴板（用户反馈不要覆写），界面直接显示管理页网址并配“复制网址”按钮；扩展路径同样直接显示并配“复制扩展路径”按钮，进入管理页后粘贴即用。早期版本的“自动粘贴地址”方案因真实多配置环境不可靠而移除。
- “加载完成后打开工作台”补充失败原因指引：无法访问意味着扩展尚未在当前配置加载或激活配置不一致。
- Edge 156 实测确认外部进程无法通过命令行参数、`microsoft-edge:` 协议或 `--app=` 打开内部管理页；自动化仅覆盖地址栏粘贴，不替代任何浏览器确认动作。
- 修复原“打开扩展管理页”按钮无明显反馈的问题；管理入口在准备文件前也可使用；首次准备使用同一入口，浏览器启动失败不再误报文件安装失败。
- 补充实际 WinForms 按钮、系统剪贴板、真实浏览器新窗口及管理页到达检查；交付要求 Edge 与 Chrome 当前 EXE 均通过按钮验收。

## 1.1.0 — 2026-10-27

- 新增 Windows Microsoft Edge 支持和独立安装包，保留 Chrome 支持；两个浏览器共享同一套 MV3 资源，无新增权限和服务。

- 更新设置页支持范围、Edge 安装/原目录升级/迁移说明，工作台版本号跟随 package 版本。

## 1.0.0 — 2026-10-27

首次可安装交付版本。由空目录依次完成本地事项管理、可解释规则、多来源真实离线解析、数据备份、安全边界、Chrome 验收和安装交付；中间阶段没有对外发布版本。

- 文字和主动网页采集，选区优先、表单排除、重复网址提示、受限页提示。
- 截图上传/拖入/真实剪贴板粘贴，中文英文离线 OCR、原图预览旋转。

- 原始输入与任务先存；可编辑草稿、候选依据、截止核对、任务计划、清单与完成归档。
- IndexedDB schema v1、关联清理、跨页面同步、跨窗口解析锁、取消和中断恢复。
- 搜索筛选排序、自然日今日/逾期规则、完整 ZIP 备份与校验、新副本合并恢复。
- 生产 MV3 CSP/本地 Worker/WASM，全部 OCR/PDF 资源随包；源码锁文件、指南、许可、演示及 PPT 提纲。
