# 校事笺隐私说明

适用版本：1.2.0；更新日期：2026-10-27。本文可作为商店提交的隐私正文草稿；公开发布前由所有者补充真实支持联系信息和公开 URL。

校事笺是本地校园通知管理扩展，不要求注册账号，不连接模型 API 或云 OCR，不设应用服务器，不收集使用统计或遥测。

通知、主动采集的网页正文、图片/附件、识别正文、日期和材料候选、个人任务及完成状态保存在当前浏览器的扩展数据库。显示设置保存在当前浏览器扩展存储中。Chrome、Edge 及其不同浏览器配置之间的数据各自保存，不自动上传或同步。

网页只在用户主动点击扩展后采集当前有权查看的可见正文或选区；不读取密码、Cookie、浏览历史或表单。图片仅在用户上传、拖入或主动粘贴时接收，不持续读取剪贴板。

截图 OCR 使用随安装包提供的简体中文/英文预训练识别数据，在本机 Worker 和 WASM 中运行。PDF/DOCX 解析也在本机执行。浏览外部原文链接需要网络，并受目标网站自己的隐私条款约束。

用户可以删除单条通知与关联文件、清除全部数据、导出完整备份，以及在另一个浏览器恢复。备份含原文件和状态，未额外加密，需由用户妥善保管。卸载扩展、清理浏览器或浏览器配置损坏可能导致数据丢失。

可选的 Windows 安装助手仅将随包资源放入当前用户本地目录、创建桌面入口，并按用户操作打开浏览器管理页。它不读取浏览历史或账号信息，不写浏览器强制安装策略，不提供云同步。点击准备安装时会将安装路径写入剪贴板以便首次选择目录；不读取剪贴板已有内容。

校事笺没有广告或将个人数据出售给第三方的功能。用户设备、本机浏览器及导出的备份仍需用户自行管理安全。
