# 约三分钟演示脚本

全部使用 `tests/fixtures` 中非敏感生成样例；这些是测试素材，不是固定解析结果，不是用户原比赛截图。

| 时间 | 操作与讲述 |
| --- | --- |
| 0:00–0:25 | 介绍校园通知散在群聊、网页和附件的困扰。打开本地工作台，强调无需账号、密钥或服务器。 |
| 0:25–0:50 | 打开导入页，展示单项/批量两个入口及拆分预览。保存一则通知，依次查看主标题、可编辑概述与原文，即使无日期也先收录。 |
| 0:50–1:20 | 上传 `notice-zh.png`，等待真实本地 OCR。展示原图、实际识别正文和带依据的日期候选。按需在正文修正错字。 |
| 1:20–1:45 | 导入 `notice-table.docx` 或 `text-multipage.pdf`，展示段落、表格行或页码。扫描 PDF 可用 `scanned.pdf` 选择第 1 页识别。 |
| 1:45–2:10 | 对照原文直接修改主截止日，展示即时保存。说明初审/评选另列、缺年不乱填、人工修改保留；安排一条今天的个人任务。 |
| 2:10–2:35 | 回首页看截止排序和今日清单。勾选一项材料，说明“准备完不等于已提交”。刷新/重开，勾选和原文仍在。 |
| 2:35–3:00 | 展示未完成/完成切换及左侧MCP配置入口，再导出备份。展示实测记录；说明本地试用、OCR/版面边界及下一步收集同学反馈。 |

不要声称：学校官方接入、所有网页可读、OCR 全部准确、已公开上线、已获得用户规模或奖项。若临场 OCR 失败，展示原件已保存与可手动修正的流程，如实说明。
