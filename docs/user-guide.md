# 中文使用指南

## 安装与开始

可直接使用单文件便捷安装助手 `xiaoshijian-1.6.0-setup.exe` 自动准备资源、入口和目录；在浏览器首次确认加载后，默认设置和欢迎页会自动出现。无需手动填写配置。完整步骤、EXE 来源确认和旧版迁移见 `install-assistant.md`。

支持 Windows Microsoft Edge 和 Google Chrome，本轮实测 Edge 156 / Chrome 156。解压对应生产 ZIP → Edge 打开 `edge://extensions`、开启开发人员模式（Chrome 为 `chrome://extensions`、开发者模式）→ “加载解压缩的扩展 / 加载已解压的扩展程序” → 选择有 `manifest.json` 的扩展文件夹。固定工具栏图标，点击“打开我的工作台”。不需要启动终端或服务器。Edge 的详细安装与迁移见 `edge-guide.md`。

## 收录通知

**一项日程**：点击左侧“导入日程”，选择“导入一项日程”，粘贴正文后点“保存原文并整理”。一次选择的多个附件归入同一项日程；也可选择“关联通知”追加到已有日程。原文先保存，再识别；没有日期也能保存。

**多项日程**：选择“一次导入多项日程”。粘贴多项正文后可按单独一行 `---`、空行或每行拆分，检查预览后批量保存；`---` 模式保留每项内部的段落换行。也可一次选多个文件，每个文件独立创建一项日程。每批最多 50 项，保存后会列出各项入口。文件整批校验通过后统一保存，非法文件不会留下半批数据。

**网页**：先打开你有权查看的普通 http/https 网页，点击校事笺图标，再点“整理当前网页 / 选中文字”。选中正文时优先采集选区，否则从正文区域采集可见文字。只填链接不会读取远程全文；受限页或需要登录的公众号请自行打开后采集，或粘贴文字/截图。相同网址会提示打开已收录通知或另存一份。

**截图**：在导入页选择、拖入 PNG/JPEG/WebP，或主动按 Ctrl+V 粘贴截图。原图先保存，再进行本地中文/英文 OCR。详情中可预览原图、旋转 90°，再点“重新读取原文件”。识别有误时直接修改已保存正文。

**PDF**：文件导入后逐页读取正文，保留页码。没有有效文字的页自动进行 OCR，每批最多 10 个扫描页；超过限额的页会明确标为“待扫描 OCR”。在详情的“原文”区域展开文件，输入 `1,3-5` 等页码并点“识别选定扫描页”继续。其他页正文保留，显示每页实际完成状态。加密 PDF 本版不接收密码，请在原软件解密导出后导入。

**DOCX**：读取真实段落和表格行，单元格以 ` | ` 分隔。不运行宏，不展示文档 HTML。旧 `.doc`、受保护或损坏文档请在 Word/WPS 另存为 DOCX 或 PDF。外部链接内容和未嵌入文档的附件不会被自动读取。

导入前的“关联通知”可选择已有通知；后来的来源与候选会追加，已确认的截止日不会被覆盖。

## 工作台速览

首页顶部并排显示“今日要办 / 材料已备 / 未完成”，下面的四张指标卡可点击，直接查看今日、即将截止、未完成、已逾期日程。左侧“所有日程”包含两种状态，也可分别进入“未完成”或“完成”列表。

每条通知卡片会显示剩余时间（今天截止、明天截止、N 天后、逾期 N 天）和材料进度条；左侧色条在逾期时为红色、三日内为琥珀色。日期旁标“机器候选 · 待核对”表示截止日还没人工确认，请进详情核对。

今日清单里的个人任务可直接点右侧 ✓ 完成，不必进入详情页。

详情自上而下显示“主标题 → 内容概述 → 原文”，第一份原文默认展开。主截止日期和可选时刻直接显示，选好即保存，也可以点“今天 / 明天 / 一周后”或清空；材料区有进度条，剩余未备时可点“全部标记已备”（提交动作仍需你自行完成）。

键盘快捷键：`/` 聚焦搜索、`Esc` 清空搜索并退出、`N` 收录新通知。输入框内输入时快捷键不生效。

## 核对与安排

- 详情先展示标题、概述和原文，下方默认选中“待办与日程”。自动提取事项按行展示，日期和时刻可修改，依据默认折叠。列表较长时在列表内滚动；材料与时间依据仍可切换页签。
- 核对后点击右上角常驻的“确认日程”，将已勾选且有可靠时间的事项加入个人任务，同时确认当前主截止日。可选事项默认不选；无时间、缺年、暂定或多时间的事项仍留待确认，不自动套用今天。重复点击不会重复安排同一任务。
- 也可上传 UTF-8 编码的 TXT/Markdown 文件；只提取纯文字，原文件随备份保留。旧通知首次打开时会从已保存正文补提取待办，不重新上传文件。
- 标题、内容概述、原文、材料名称在编辑后离开输入框时保存；截止日、状态与勾选即时写入本地数据库。人工概述不会被重识别覆盖。
- 日期候选旁有原文、来源/页码、规则编号和文本区间。点击“选为已确认截止日”，或在顶部直接修改日期与可选时刻。“清空截止日”会保留你的选择，不在下次提取时重新自动填入。
- 缺年份不使用电脑年份补齐；无效日期不可选入主截止日；没有时刻不补 23:59；暂定、相对和其他活动时间单独展示。多个来源的冲突日期均保留供你选择。
- 材料可增加、修改、删除、勾选，也能设置必交候选/可选/无需提交。重提取不清空人工修改与勾选。材料全部准备完不会自动标成已提交。
- 个人任务输入内容、计划日期后点击“安排任务”。首页今日清单来自今天的个人任务或已人工确认的今日截止日；自动候选仅显示“可能今日截止 / 待核对”。日期到天的事项当天不会因过了零点就标逾期。
- 通知状态仅有“未完成”和“完成”。选择“完成”后离开首页今日清单，在“完成”或“所有日程”查看；改回“未完成”即可继续安排。升级时旧待核对/进行中归为未完成，旧完成/归档归为完成。删除通知会同时删除关联原件、清单、任务与处理记录。

## 识别进度、取消和中断

处理记录显示等待、处理中、成功、部分成功、失败和已取消。可取消长任务，原件仍在。为控制内存，同一扩展所有窗口一次只运行一个重任务。

关闭工作台或退出浏览器会中断解析。重开后若记录仍是“处理中”，表示可能已中断，点击“重试 / 继续处理”。不会宣称关闭页面后仍持续可靠识别。部分完成的 PDF 页和原件保留，失败时仍可手工填写正文。

## Agent 通过 MCP 添加日程

使用安装助手更新后，点击左侧“MCP 配置”，勾选“启用本地 MCP”，看到“已连接”后生成并复制配置，加入你的本机 MCP 客户端。agent 可调用 `add_schedule` / `list_schedules`，添加后直接保存到个人任务；浏览器需保持运行，工作台页面可关闭。关闭再启用会使旧配置失效。参数、ZIP 注册与排错见 [MCP 指南](mcp-guide.md)。

## 备份、恢复与卸载

设置 → “导出完整备份 ZIP”。备份包含通知、原文、日期与材料依据、任务、勾选、处理记录、所有原文件。界面偏好属于当前浏览器设置，不随备份迁移。

恢复：选择 ZIP → 等待格式、schema、关联、路径、大小及附件 SHA-256 校验 → 查看数量 → 点击“确认合并恢复”。全部作为新 ID 副本加入，已有数据不覆盖；重复恢复会新增副本。中断的任务需手动重试。

Chrome 与 Edge 各自保存数据库，不会自动同步。可在 Chrome 导出完整备份，再在 Edge 按上述步骤恢复；本轮已实际验证跨浏览器恢复与附件校验。显示偏好不随数据迁移。

备份不加密，请自己妥善保管。卸载前务必先导出；浏览器扩展菜单移除“校事笺”会清理扩展本地数据。重新安装后可选择备份恢复。

## 限额与隐私

单图 10 MB、2500 万像素；单个 PDF/DOCX 20 MB；PDF 100 页；扫描 OCR 每批 10 页；正文 100 万字符；DOCX 展开不超过 80 MB；备份 ZIP 不超过 100 MB/展开不超过 250 MB。超过限额请拆分、选页或缩小文件。这些是本版保护阈值，不是浏览器能力上限。

数据默认保存在本地，无遥测、内置模型 API 或云 OCR；启用 MCP 后，所配置的 agent 可以添加和查询个人日程。权限为 `activeTab`、`scripting`、`storage`、`nativeMessaging`（用于可选 MCP 本地桥接）；不读取 Cookie、密码、表单、浏览历史，不持续读取剪贴板。查看外部原网页需要网络，核心导入/识别/管理可离线。

清除扩展数据、卸载或浏览器配置损坏可能丢数据，定期备份。更多边界见 `known-limitations.md`。
