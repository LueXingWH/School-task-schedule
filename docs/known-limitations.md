# 支持边界

- 本版为本地加载试用扩展，未上架应用商店。不能双击 ZIP 安装。
- 1.2.0 提供单文件便捷安装助手，自动准备文件/入口/默认配置，首次仍需浏览器确认侧载，不是商店一键安装或静默强制安装。EXE 未签名，Windows 可能要求确认来源；商店提交包与材料已准备，尚未提交或审核。
- Windows Microsoft Edge 与 Google Chrome 已验证支持，实测 Edge 156.0.4314.42 / Chrome 154.0.8037.100；manifest 的 Chromium 最低版本仍为 154，更旧版本及其他操作系统不在本轮支持验证范围。
- Chrome 和 Edge 分别保存本地数据，不自动同步；可用完整备份迁移。本版未上架 Microsoft Edge Add-ons 或 Chrome 商店。
- 不接入微信/QQ 客户端，不自动监控群聊或自动报名，不绕过网站的登录/访问限制。
- 本地 OCR 使用 Tesseract LSTM 简体中文/英文预训练数据；复杂海报、竖排、低分辨率、艺术字体、模糊数字和复杂表格会有错误，必须核对关键日期和材料。
- PDF 文本按行坐标近似还原顺序，复杂多栏/跨页表格可能需要手动整理。扫描页需明确选择页码，不自动将所有页重复 OCR。加密 PDF 请先解密导出；不保存密码。
- DOCX 支持正文段落和表格行；不支持旧 DOC、外链附件的内容、受保护文档。格式和分页不承诺忠实还原。
- 规则提取是可解释的关键词/日历校验；材料名称只识别常见材料词及相关段落，复杂否定、跨段指代和含糊日期可能需人工更正。规则回归通过不代表所有通知或 OCR 的准确率。
- 无系统通知、云同步、账号、日历导出和桌面后台服务；今日任务来自已确认截止日或人工安排，页面每 30 秒按当前本地日期重算。
- 工作台关闭会中断长解析，重新打开可手动重试；一次运行一个解析任务。任务记录的成功表示解析已完成，日期材料仍待核对。
- 备份采用新副本合并；重复恢复会产生重复通知。界面偏好留在当前浏览器，不随数据备份迁移。清除/卸载前请导出备份。
- 文件、页数和内存保护限额是本版初始阈值，已用小型真实文件验证，尚未宣称所有设备在阈值极限下的性能。
- 本地数据库未额外加密；设备/浏览器账号安全由使用者管理。没有服务端收集正文或附件。
